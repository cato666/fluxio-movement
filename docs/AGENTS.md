# Movement Coach MVP

Stack:
- Python 3.11
- FastAPI
- PostgreSQL
- MediaPipe
- OpenCV
- FFmpeg
- Docker Compose

Reglas:
- Evolucionar el proyecto actual, no recrearlo.
- No cambiar arquitectura sin necesidad.
- Mantener compatibilidad con el analizador existente.
- Trabajar una fase a la vez.
- Ejecutar primero tests específicos.
- Ejecutar suite completa solo al cerrar una fase.
- No reconstruir Docker salvo cambios en dependencias,
  Dockerfile, compose o migraciones que lo requieran.
- No implementar funcionalidades fuera de la fase solicitada.
- No generar documentación extensa salvo que se solicite.
- Respuestas finales breves:
  archivos cambiados, tests y problemas.
